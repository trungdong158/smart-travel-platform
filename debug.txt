LỖI VERCEL: [MISSING_SERVICES]

Thông báo:
Project framework is set to "services", but no services are declared.

Nguyên nhân:
1. Framework Preset của Vercel project đang được đặt là "Services", nên Vercel mong đợi cấu hình khai báo danh sách services.
2. Dự án không triển khai theo mô hình Vercel Services. vercel.json hiện cấu hình Vite build frontend, xuất client/dist và chạy backend qua Serverless Function api/index.js.
3. Vì không có thuộc tính services trong vercel.json, cấu hình Services không phù hợp và Vercel báo [MISSING_SERVICES].

Cách khắc phục đã áp dụng:
1. Thêm "framework": null vào vercel.json. Theo cấu hình Vercel, null chọn Framework Preset "Other" và ghi đè preset trong Project Settings.
2. Chọn "Other" làm Framework Preset trong Vercel Project Settings nếu dashboard vẫn hiển thị "Services".
3. Đảm bảo Root Directory là thư mục gốc repository để Vercel dùng đúng vercel.json, client/ và api/.
4. Commit/push cấu hình mới hoặc chạy deploy lại sau khi thay đổi; kiểm tra build và API tại /api/health.

Không thêm services vào cấu hình vì dự án vẫn dùng kiến trúc một project với frontend tĩnh và API serverless, không phải mô hình Vercel Services.
